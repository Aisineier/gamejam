# 麦穗余晖

用 Godot 4.5.1 打开 `project.godot`，按 **F5**。从主菜单开始新游戏后，会进入可跳过的全屏水墨序章。

主菜单可开始新游戏、继续存档或关闭游戏。农场支持自动存档，也可点顶部「存档」手动保存。新游戏进入农场后会替换当前存档。主菜单、序章和农场各自播放一首原创循环配乐。

## 河湾村的两年

- 开局有 200 金币、10 声望、5 点每日劳力。开垦菜地、养鸡和卖菜，攒到 400 金币触发车站剧情，花 500 金币修葺车站。
- 每月有 30 天。青菜、土豆、草莓及猪、蜂、牛按月份解锁。鸡蛋可摸走售卖，也可留蛋 3 天孵化。满栏时，新孵出的小鸡等空栏后补入。
- 步行售卖花 2 劳力，收原价的 90%。班车售卖免劳力，收原价。修路另加 10%，网络基站开启物流和每日自动出货。养殖用的成年鸡由玩家手动出售。
- 第 10 月可建设池塘观景台，再扩建树林露营区。每日也可结算游客收入和电商订单。低声望会提高月度风险，关键剧情的选择会改变金币、声望或经营条件。
- 「快进到下一事项」最多推进 30 天，在新作物成熟、孵化结果、养殖产出、月初或剧情时停下。跳过的日期仍逐天结算。

## 结局

第 24 月末按 S、A、B、C 的顺序判定。

| 结局 | 金币 | 声望 | 条件 |
| --- | ---: | ---: | --- |
| S 圆满 | 15000 | 60 | 至少 3 项改造，开启电商或 2 位青年回村 |
| A 小康 | 8000 | 40 | 至少 2 项改造，通车并开启旅游或电商 |
| B 维持 | 3000 | 20 | 达到金币和声望门槛 |
| C 遗憾 | | | 未达到前三档 |

经营规则、数值和事件数据见 `scripts/village.gd`，界面和演出见 `scripts/main.gd`。
